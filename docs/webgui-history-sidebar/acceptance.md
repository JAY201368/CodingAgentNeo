# Web GUI 历史侧边栏 scripted 验收对照

本表把 T07 要求的 scripted Web 验收项映射到既有 Vitest 证据。缺口才补测试，不另造第二套协议或真实模型旅程。

Python 聚合验收 `tests/acceptance/test_webgui_history_sidebar_acceptance.py` 只做静态边界扫描（`v-html`、Python import、fetch/localStorage 所有权、git 生成物/secret、README 运行说明），不冒充真实浏览器或真实模型网关。

| 验收项 | 证据（文件 / 用例名） | 说明 |
| --- | --- | --- |
| 列出历史 | `web/src/composables/useSessionHistory.spec.ts` — `loads the first page without a cursor or default limit`；`web/src/components/HistorySidebar.spec.ts` — `renders summaries, timestamps, states, and resumable flags in list order`；`web/src/App.spec.ts` — `places the title in the sidebar and keeps the conversation in a centered main column`；`lists history and pages with the opaque next_cursor` | 首页 `GET /api/v1/session-history` 无 cursor；侧边栏按传入顺序展示有界摘要 |
| 分页 | `web/src/composables/useSessionHistory.spec.ts` — `echoes next_cursor verbatim on loadMore and appends items`、`passes an opaque injected cursor through unchanged and does not decode it`、`does not re-enter loadMore or duplicate items when triggered repeatedly`；`web/src/components/HistorySidebar.spec.ts` — `shows load more when hasMore and emits loadMore`；`web/src/App.spec.ts` — `lists history and pages with the opaque next_cursor` | App 点击「加载更多」把不透明 cursor 原样回送并追加，不解码为 offset/ID/路径 |
| 点击切换：终结当前 + resume + 历史消息重现 | `web/src/App.spec.ts` — `resumes the selected history session, hydrates turns, and allows follow-up`；`web/src/composables/useAgentSession.spec.ts` — `terminates, resets, resumes, hydrates in sequence, then attaches SSE from the reducer cursor` | 顺序为 DELETE 当前 transport → RESET → `POST {resume_session_id}` → 有限 JSON hydration → live SSE；SSE 不 replay 历史 |

| hydration 幂等 / 跳号 | `web/src/composables/useAgentSession.spec.ts` — `ignores duplicate sequences and keeps a gap diagnostic without crashing`、`pages history with next_cursor as the next since until has_more is false`；`web/src/domain/reducer.spec.ts` — `advances on ordered facts, makes replay idempotent, and diagnoses gaps` | 重复 sequence 忽略；跳号保留诊断并停止推进 cursor |
| follow-up | `web/src/App.spec.ts` — `resumes the selected history session, hydrates turns, and allows follow-up`；`web/src/composables/useAgentSession.spec.ts` — `terminates, resets, resumes, hydrates in sequence, then attaches SSE from the reducer cursor`（末尾 `submitTask('follow-up')`） | 恢复后同一 transport session 可提交后续任务 |
| 未知 / 截断 payload 降级 | `web/src/domain/history.spec.ts` — `ignores unknown fields and degrades missing, illegal, truncated, and oversized input`、`parses shared event pages, empty pages, and truncated payload previews`；`web/src/api/client.spec.ts` — `degrades truncated, unknown, and bad diagnostics from live history responses`；`web/src/composables/useAgentSession.spec.ts` — `retains unknown and truncated history events without crashing`；`web/src/domain/reducer.spec.ts` — `preserves canonical metadata and unknown fields while recognizing truncation`、`keeps unknown event types safe and uses turn_end as the completion boundary` | 未知字段保留、截断标记、坏 candidate 不使整表失败、不抛未捕获异常 |
| historySessionId 与 transport ID 不混用 | `web/src/composables/useAgentSession.spec.ts` — `does not send a history id on transport routes or a transport id on history routes`、`does not DELETE the current session when the history id is illegal`、`rejects illegal history id %s before POST or history GET`；`web/src/domain/history.spec.ts` — `keeps transport and canonical session IDs as distinct nominal types`、`accepts opaque session_ tokens and rejects path-like or transport IDs`；`web/src/App.spec.ts` — `resumes the selected history session, hydrates turns, and allows follow-up`（DELETE 路径含 `transport_app_live`、不含 history ID） | 历史读取用 canonical `session_id`；DELETE/SSE/commands 用 transport ID；非法 ID 在终结当前之前失败 |

## 明确未声称的证据

- 真实模型网关、真实浏览器端到端 resume、公网/远程部署均未在本工作流执行。
- T06 人工 1280/360 布局检查是离线视觉证据，不替代本表的 resume 状态机证据。
- 既有 `tests/acceptance/test_web_frontend_acceptance.py` 覆盖 live HTTP/SSE 任务/工具/授权/follow-up，不覆盖历史侧边栏 UI；历史 list/events/resume 的 Python wire 证据在 `tests/integration/test_http_history.py` 与前序 `docs/backend-history-discover/`。
